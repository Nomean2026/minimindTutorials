📐 大模型是什么？

MiniMind 整体架构鸟瞰——"把大象装进冰箱需要几步？"

🤔 我们到底在做什么？

大语言模型（LLM）本质上就是一个超级复杂的 next token prediction（下一个词预测）机器。

给它一段文本，它预测下一个最可能出现的 token——然后把这个 token 拼上去，再预测下一个，一直重复下去。

💡 一句话总结：大模型 = "根据上文猜下文"的循环预测器。

🏗️ MiniMind 架构一览

MiniMind 是一个 Decoder-Only Transformer 架构（和 GPT、Llama 一样）。它的整体结构如下：

🔤 Token Embedding（词嵌入）
↓
🔄 Transformer Block × 8
┌─ Self-Attention（自注意力） ─┐
└─ Feed-Forward（前馈网络） ──┘
↓
📏 RMS Norm（层归一化）
↓
🎯 LM Head（映射到词汇表）

和它背后的核心代码一一对应：

class MiniMindForCausalLM(PreTrainedModel): def __init__(self, config): self.model = MiniMindModel(config) # 预测头：hidden → vocab self.lm_head = nn.Linear( config.hidden_size, config.vocab_size ) # 权重绑定（节省参数） if config.tie_word_embeddings: self.model.embed_tokens.weight = \ self.lm_head.weight def forward(self, input_ids, labels=None): # 通过主干网络 hidden_states, presents, aux_loss = \ self.model(input_ids) # 映射到词汇表 logits = self.lm_head(hidden_states) # 计算损失 if labels is not None: loss = F.cross_entropy( logits.view(-1, vocab_size), labels.view(-1), ignore_index=-100 ) return logits, loss

这就是整个模型的最外层——一个 CausalLM（因果语言模型）。

它包装了 MiniMindModel（主干网络），加上一个 lm_head 投影到词汇表。

tie_word_embeddings：embedding 层和 lm_head 共享权重，因为输入和输出都是同一个词汇空间。

🧱 MiniMind 核心配置

参数值含义

vocab_size6400词汇表大小
max_position_embeddings32768最大序列长度

📐 一个 token 的旅程

让我们跟踪一个 token 从输入到输出的完整流程：

  1. 输入：文字 "我" → tokenizer 把它变成数字 ID（比如 523）
  2. 嵌入：Embedding 层把 523 变成 768 维向量 [0.12, -0.34, ..., 0.56]
  3. 8 个 Transformer Block：每个 Block 都让这个向量"看看周围的 token"（Attention）再"思考一下"（FFN）
  4. RMS Norm：归一化，让数值稳定
  5. LM Head：把 768 维向量映射回 6400 维（每个词一个分数），softmax 后取概率最高的词

🔢 参数量估算

MiniMind 到底有多大？我们来算一下：

组件公式参数量
Embedding6400 × 7684.92M
Attention QKV (×8)8 × (768×768 + 768×384 + 768×384)8.85M
Attention O (×8)8 × 768 × 7684.72M
FFN (×8)8 × (768×864 × 3)15.93M
LM Head768 × 6400（与 Embedding 共享）0（共享）
总计~34.4M
💡 对比一下：GPT-2 有 1.5B（15 亿）参数，Llama-3-70B 有 700 亿。MiniMind 的 34M 是 GPT-2 的 1/44，但麻雀虽小五脏俱全！

📝 本章小结

  1. 大模型 = next token prediction——不断预测下一个词
  2. MiniMind 是 Decoder-Only Transformer，8 层，768 隐藏维度
  3. 架构：Embedding → 8×Transformer Block → RMS Norm → LM Head
  4. 总参数量约 34.4M（合适学习的小模型）
  5. 代码入口：MiniMindForCausalLM 类
