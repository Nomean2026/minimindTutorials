🎲 SFT 推理生成

采样策略解密：top-k、top-p、temperature——让模型不只会"背诵"

📖 前情提要

SFT 之后，模型学会了对话格式。但真正用的时候，还有一个关键问题：模型每次回答同一问题，应该一样吗？

🎯 从"背诵"到"创作"

训练完成后，模型本质上是一个概率分布：给定前面的 token，它知道下一个 token 该是什么。

但知道"该是什么"和"选什么"是两回事：

💡 比喻一下：模型就像一个学会了无数成语的人。他知道在"天气真"后面可以接"好"、"棒"、"不错"、"暖和"…… 如果每次都选概率最高的"好"，那千篇一律。如果随机选一个，可能选到奇怪的组合。 好的采样策略就是找到"多样性"和"合理性"的平衡点。

🥶 Temperature：调节"自信程度"

Temperature 是最基础也最重要的采样参数：

# 原始 logits
logits = [2.0, 1.0, 0.5, 0.1]

# 除以 temperature
logits = logits / temperature

# 然后做 softmax
probs = F.softmax(logits, dim=-1)

Temperature 的作用：

T → 0：概率分布趋于 one-hot，总是选最可能的 token（确定性）

T = 1：保持原始分布

T → ∞：所有 token 等概率（完全随机）

MiniMind 默认用 0.85，偏保守但留有一定创造力。

数学公式：P(xᵢ) = exp(logitᵢ / T) / Σⱼ exp(logitⱼ / T)

🎯 Top-K：只从"K 个候选人"里选

# Top-K 过滤
if top_k > 0:
  values, _ = torch.topk(logits, top_k)
  threshold = values[..., -1, None]
  logits[logits < threshold] = -inf

Top-K 的思路：只保留概率最高的 K 个 token，其他的概率置零。

好处是避免了"长尾概率"的干扰——不会选到概率很低的奇怪 token。

MiniMind 默认 top_k = 50。

🔝 Top-P（Nucleus Sampling）：动态候选集

# Top-P (nucleus) 过滤
sorted_logits, sorted_indices = torch.sort(logits, descending=True)
cum_probs = torch.cumsum(F.softmax(sorted_logits, dim=-1), dim=-1)
mask = cum_probs > top_p
mask[..., 1:] = mask[..., :-1].clone()
mask[..., 0] = 0
logits[mask.scatter(1, sorted_indices, mask)] = -inf

Top-P 的思路：选取概率累积和达到 P 的最小 token 集合。

如果分布很尖锐（某个 token 概率 90%），只需要 1-2 个 token。

如果分布很平坦，会选更多 token。

MiniMind 默认 top_p = 0.85。

🔄 采样策略对比

策略原理优点缺点
Temperature缩放 logits连续控制"创造力"不能过滤低概率 token
Top-K固定 K 个候选人简单直接K 需要人工调，不同场景最优 K 不同
Top-P累积概率到 P自适应候选数极端分布下退化成 greedy
三者组合先 top-k，再 top-p，再 temperature兼顾稳定性和多样性超参数多

📝 本章小结

推理生成的核心是平衡确定性和多样性：

  • Temperature：控制整体"随机性"
  • Top-K：砍掉长尾概率
  • Top-P：动态保留"核心"概率
  • Repetition Penalty：惩罚重复出现的 token，防止重复循环
