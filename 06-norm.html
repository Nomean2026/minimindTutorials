📏 层归一化（RMSNorm）

"稳住，别让数值飞了"——为什么大模型需要 RMSNorm 而不是 LayerNorm

📖 快速复习：前面我们学了 Attention 和 FFN，它们内部都有很多线性变换和激活函数。 如果没有归一化，经过多层叠加后数值会越来越大或越来越小（梯度消失/爆炸）。 归一化就是给每一层的输出"踩刹车"。

🎯 为什么要归一化？

随着网络层数加深，每一层的输出分布会发生变化（内部协变量偏移）。具体来说：

  • 数值会越滚越大：Attention 的输出 + 残差连接 + FFN = 数值范围逐渐失控
  • 梯度会消失：sigmoid/tanh 在输入很大时梯度接近 0
  • 训练不稳定：不同 batch 的数据分布差异大

📐 RMSNorm vs LayerNorm

原版 Transformer 用的是 LayerNorm，MiniMind（和 Llama）用的是 RMSNorm。

LayerNorm：x̂ = (x - μ) / σ   y = γ · x̂ + β
RMSNorm：x̂ = x / RMS(x)   y = γ · x̂

其中 RMS(x) = √(1/d · Σ xi²)
LayerNorm 计算均值和方差，RMSNorm 只算均方根！

LayerNorm

  • 减均值 → 除方差 → 缩放+平移
  • 需要 2 次统计量 + 2 个可学习参数
  • 计算量大 15-20%
  • 原版 Transformer 在用

RMSNorm ✅

  • 只用均方根归一化
  • 只需要 1 个可学习参数（γ）
  • 计算量减少 ~15%
  • Llama / MiniMind 在用

🧩 MiniMind 中的 RMSNorm

class RMSNorm(torch.nn.Module): def __init__(self, dim, eps=1e-5): super().__init__() self.eps = eps # 可学习的缩放参数 self.weight = nn.Parameter( torch.ones(dim)) def norm(self, x): # RMS = √(mean(x²) + eps) return x * torch.rsqrt( x.pow(2).mean(-1, keepdim=True) + self.eps ) def forward(self, x): # x ∈ [batch, seq, dim] # 在最后一维（dim）上做归一化 output = self.norm(x.float()) return (self.weight * output).type_as(x)

只有 4 行核心逻辑！

x.pow(2).mean(-1)：对每个 token 的 768 维向量求平方均值 → [batch, seq]

rsqrt(… + eps)：求平方根的倒数（1/√(·)），比先 sqrt 再除法快

x * rsqrt(…)：归一化，使每个向量的 RMS ≈ 1

self.weight * output：可学习的缩放（每个维度有自己的缩放系数）

为什么不用 bias（β）？ 实验表明 LayerNorm 的 bias 对效果影响极小，RMSNorm 直接去掉，省了 768 个参数/层。

🏗️ RMSNorm 在模型中的位置

在 MiniMind 中，RMSNorm 出现在三个地方：

位置作用
self.input_layernorm（每个 Block）Attention 之前，归一化输入
self.post_attention_layernorm（每个 Block）FFN 之前，归一化 Attention 输出
self.norm（模型最后）最终输出层前归一化
q_norm / k_norm（Attention 内）Q 和 K 的 head 维度归一化
💡 Pre-Norm vs Post-Norm：MiniMind 使用的是 Pre-Norm（归一化放在子层之前）。 这是现代 LLM 的标准做法（相比原版 Transformer 的 Post-Norm），训练更稳定，可以支持更深的网络。

📝 本章小结

  1. 归一化的目的：防止深层网络的数值爆炸/消失，稳定训练
  2. RMSNorm vs LayerNorm：只求均方根、只用一个可学习参数、快 15%
  3. RMSNorm 公式：x / √(mean(x²) + ε) × γ
  4. Pre-Norm 结构：归一化放在 Attention/FFN 之前
  5. MiniMind 中的 4 处使用：input_layernorm、post_attention_layernorm、final norm、QK norm
🤔 思考题：RMSNorm 去掉了均值中心化（不减均值），为什么还能正常工作？

💡 点击查看答案

这是一个很好的问题！LayerNorm 减均值是为了让数据居中（零均值），但 RMSNorm 只做缩放不做平移。

RMSNorm 能工作的原因：

  1. 残差连接保留均值：虽然归一化没做均值中心化，但残差连接 (x + F(x)) 保留了输入的均值信息——如果输入本来均值不为 0，残差会自然带着走
  2. 归一化的核心是缩放：对 Transformer 来说，控制方差比控制均值更重要。因为 Attention 的点积对数值范围极其敏感（QK.T 的方差过大会让 softmax 太尖锐）
  3. Llama 的实践证明：去掉均值中心化没有明显影响，却省掉了计算均值的开销

一句话：减去均值是冗余的——残差连接已经天然做了"去均值"的效果。
