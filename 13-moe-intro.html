🔬 MoE 概念入门

Dense vs MoE：参数量与计算量的博弈——"天下没有白来的午餐"

📖 前情提要

我们之前学的 MiniMind 模型是 Dense（稠密）架构：每个 token 经过每一层时，所有的参数都被激活。

MoE 的思路是：既然不是所有 token 都需要同样的"知识"，为什么不让不同的专家处理不同类型的 token？

🏢 从"全能员工"到"专家团队"

想象你开了一家公司：

  • Dense 架构 = 每个员工都是全能的，什么活都能干。但每个人都要学所有技能，效率不高。
  • MoE 架构 = 公司分成几个部门（专家），每个部门专精一个领域。来一个任务，先由"路由"判断该交给哪个部门。
Dense vs MoE：MoE 有更多的参数（4 个专家），但每个 token 只激活其中 2 个

⚡ 核心 Insight：参数量 vs 计算量

这是理解 MoE 最重要的一个概念：

🔧 Dense 模型

参数量 = 计算量

所有参数都被激活，参数量越大，计算量越大。

🧠 MoE 模型

参数量 >> 计算量

参数总量大，但每个 token 只激活一部分专家。

用视频里的话来说："空间复杂度没有变，甚至可能更高了，但是时间复杂度可以减小"。

💡 "天下没有白来的午餐"——MoE 是用空间（更多参数）换时间（更少计算）。 你得到了：更多的模型容量 + 相同的推理速度。你付出了：更多的显存来加载所有专家参数。

📊 MiniMind 中的实现对比

来看 MiniMind 中 Dense 和 MoE 的代码对比：

# FeedForward（Dense）
class FeedForward(nn.Module):
  def __init__(self, config):
    self.gate_proj = nn.Linear(...)
    self.down_proj = nn.Linear(...)
    self.up_proj = nn.Linear(...)

  def forward(self, x):
    return self.down_proj(
      act(self.gate_proj(x)) * self.up_proj(x)
    )

Dense MLP：经典的 SwiGLU 结构。

每个 token 经过3 个线性层，所有参数都被激活。

计算量 = 参数量 = 3 × hidden_size × intermediate_size

# MOEFeedForward
class MOEFeedForward(nn.Module):
  def __init__(self, config):
    # 路由网络
    self.gate = nn.Linear(hidden_size, num_experts)
    # 多个专家
    self.experts = nn.ModuleList([
      FeedForward(config)
      for _ in range(num_experts)
    ])

MoE MLP：多了两部分：

  1. Router（gate）：一个线性层，决定每个 token 去哪个专家
  2. N 个专家：每个专家都是一个完整的 FeedForward

参数量 ≈ N × Dense，计算量 ≈ 2/N × Dense（假设 top-2）

⚙️ 配置切换

在 MiniMind 中，切换 Dense <-> MoE 只需要一个参数：

# MiniMindConfig
self.use_moe = use_moe # True / False
self.num_experts = 4
self.num_experts_per_tok = 2

# MiniMindBlock 中
self.mlp = FeedForward(config)
    if not config.use_moe else
    MOEFeedForward(config)

就改了这么一个条件判断！

整个模型 95% 的代码在 Dense 和 MoE 之间是共享的。

训练脚本中通过 --use_moe 1 开启：

python train_full_sft.py --use_moe 1

权重保存时会自动加 _moe 后缀：

full_sft_768_moe.pth

📝 本章小结

  1. MoE ≠ Sparse：MoE 是"多个专家"，Sparse 是"只激活部分专家"，两者可以组合使用
  2. 空间换时间：MoE 参数更多但计算更少
  3. 95% 代码共享：Dense 和 MoE 只差在 MLP 层
  4. 一个参数切换：--use_moe 1 开启 MoE
  5. 专家是独立的小 MLP：每个专家就是一个完整的 FeedForward 网络
