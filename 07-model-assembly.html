🧩 完整模型组装

MiniMindModel + MiniMindForCausalLM——"把所有零件拼成一台机器"

📖 快速复习：前 6 章我们分别学了 Embedding、Attention、RoPE、FFN、RMSNorm。现在是时候把这些零件组装起来了！

🏗️ 三个嵌套类的层次结构

MiniMindForCausalLM
│ 包含一个 MiniMindModel
│ 加一个 lm_head（预测头）
↓
MiniMindModel
│ 包含 8 个 MiniMindBlock
↓
MiniMindBlock × 8
│ 每个包含 Attention + FFN

🧱 MiniMindBlock

class MiniMindBlock(nn.Module): def __init__(self, layer_id, config): # Self-Attention self.self_attn = Attention(config) # Pre-Norm self.input_layernorm = RMSNorm( config.hidden_size, eps=config.rms_norm_eps) # Pre-Norm（FFN 之前） self.post_attention_layernorm = \ RMSNorm(config.hidden_size, eps=config.rms_norm_eps) # FFN（Dense 或 MoE） self.mlp = FeedForward(config) \ if not config.use_moe \ else MOEFeedForward(config) def forward(self, hidden_states, position_embeddings, past_key_value, use_cache, attention_mask): # Pre-Norm + Attention + 残差 residual = hidden_states hidden_states = self.self_attn( self.input_layernorm(hidden_states), position_embeddings, past_key_value, use_cache, attention_mask ) hidden_states += residual # Pre-Norm + FFN + 残差 hidden_states = hidden_states + \ self.mlp( self.post_attention_layernorm( hidden_states ) ) return hidden_states, present

一个 Block 的流程：

  1. 保存残差
  2. Pre-Norm：先归一化，再进 Attention
  3. Attention 输出 + 残差
  4. 再次 Pre-Norm：归一化后进 FFN
  5. FFN 输出 + 残差

这就是经典的 Pre-LN Transformer Block！

注意 config.use_moe——如果启用了 MoE，FFN 会被替换成 MOEFeedForward。

📦 MiniMindModel——8 个 Block 的容器

class MiniMindModel(nn.Module): def __init__(self, config): # Token Embedding self.embed_tokens = nn.Embedding( config.vocab_size, config.hidden_size) # 8 个 Transformer Block self.layers = nn.ModuleList([ MiniMindBlock(l, config) for l in range( config.num_hidden_layers) ]) # 最终归一化 self.norm = RMSNorm( config.hidden_size, eps=config.rms_norm_eps) # 预计算 RoPE freqs_cos, freqs_sin = \ precompute_freqs_cis(...) self.register_buffer( "freqs_cos", freqs_cos) self.register_buffer( "freqs_sin", freqs_sin)

MiniMindModel 包含：

  1. embed_tokens：第 2 章学的词嵌入
  2. layers：8 个 MiniMindBlock（nn.ModuleList）
  3. norm：最终的 RMSNorm
  4. freqs_cos/sin：第 4 章学的 RoPE 预计算表

register_buffer：把数据注册为 buffer，不参与梯度计算，但会随模型移动设备。

def forward(self, input_ids, ...): # Embedding hidden_states = self.embed_tokens(input_ids) # 获取 RoPE position_embeddings = ( self.freqs_cos[start:start + seq], self.freqs_sin[start:start + seq] ) # 8 层 Transformer for layer in self.layers: hidden_states, present = layer( hidden_states, position_embeddings, past_key_value, use_cache, attention_mask) # 最终归一化 hidden_states = self.norm(hidden_states) # 汇总 MoE aux loss aux_loss = sum(...) return hidden_states, presents, aux_loss

forward 流程：

  1. Embedding 把 token ID 映射为向量
  2. 从预计算表中截取当前序列的 RoPE
  3. 逐层通过 8 个 Block
  4. 最终 RMSNorm
  5. 返回所有层的 KV Cache（presents）和 MoE 辅助损失

注意：这里的循环可以用 torch.compile 加速！

🎯 MiniMindForCausalLM——最外层包装

class MiniMindForCausalLM( PreTrainedModel, GenerationMixin): def __init__(self, config): self.model = MiniMindModel(config) self.lm_head = nn.Linear( config.hidden_size, config.vocab_size, bias=False) # 权重绑定（省参数！） if config.tie_word_embeddings: self.model.embed_tokens.weight = \ self.lm_head.weight def forward(self, input_ids, labels=None, logits_to_keep=0): # 模型计算 hidden_states, p, aux = \ self.model(input_ids, ...) # 只留最后 logits_to_keep 个 logits = self.lm_head( hidden_states[:, -logits_to_keep:]) # 计算损失（CausalLM） if labels is not None: x = logits[..., :-1, :].contiguous() y = labels[..., 1:].contiguous() loss = F.cross_entropy( x.view(-1, x.size(-1)), y.view(-1), ignore_index=-100) return (loss, aux_loss, logits, past)

最外层的两个重要设计：

1. 继承 PreTrainedModel：自动获得 HuggingFace 的 save_pretrained、from_pretrained 等能力

2. 继承 GenerationMixin：自动获得 generate() 方法，支持各种采样策略

logits_to_keep：只计算最后几个 token 的 logits——推理时只用最后一个 token，不需要算全部。

损失计算：logits[..., :-1] 和 labels[..., 1:] 对齐——预测每个位置的下一个 token。

📐 数据流全景图

输入: [batch, seq] — token ID（如 [523, 890, 1245]）
  │
  ▼ Embedding (6400 → 768)
  [batch, seq, 768] — 稠密向量
  │
  ▼ + Dropout
  [batch, seq, 768]
  │
  ▼ MiniMindBlock × 8（每个 Block 内）
  │  ├─ RMSNorm → Attention → + 残差
  │  └─ RMSNorm → FFN → + 残差
  │
  ▼ RMSNorm（最终归一化）
  [batch, seq, 768]
  │
  ▼ LM Head (768 → 6400)
  [batch, seq, 6400] — 每个 token 的词汇表分数
  │
  ▼ Softmax（取最后一个 token）
  [batch, vocab] — 下一个 token 的概率分布

📝 本章小结

  1. 三层嵌套：MiniMindForCausalLM → MiniMindModel → MiniMindBlock
  2. 每个 Block：Pre-Norm → Attention → 残差 → Pre-Norm → FFN → 残差
  3. Model：Embedding + 8 个 Block + 最终 RMSNorm
  4. CausalLM：包上 lm_head + 损失计算 + 继承 HuggingFace 接口
  5. 权重绑定：Embedding 和 LM Head 共享参数
  6. logits_to_keep：推理时只算最后一个 token，减少计算量
🤔 思考题：MiniMindForCausalLM 继承 PreTrainedModel 和 GenerationMixin 带来了什么好处？

💡 点击查看答案

这两个基类是 HuggingFace transformers 库的核心：

  1. PreTrainedModel：提供了
    • save_pretrained() / from_pretrained()——标准的模型保存和加载
    • post_init()——自动初始化权重
    • 自动处理 device 映射、dtype 转换等
  2. GenerationMixin：提供了
    • generate()——完整的自回归生成流程
    • 支持各种采样策略（greedy、beam search、sampling）
    • 支持 KV Cache、streamer 等高级特性

简单说：有了这两个基类，MiniMind 可以用和 GPT/Llama 一样的 API 加载和推理！
