🚦 路由网络详解

Gating Network、Top-K 选择——MoE 的"交通指挥"系统

📖 前情回顾

  • MoE = 多个专家（每个是一个 FeedForward）+ 一个路由（Router）
  • 参数量大但计算量小（只激活部分专家）
  • MiniMind 通过 config.use_moe 一个标志位切换

🧭 路由网络 = MoE 的大脑

路由网络（Gating Network / Router）是 MoE 中最核心也最有趣的部分。它的任务很简单：决定每个 token 应该交给哪些专家处理。

# MOEFeedForward.forward()
# Step 1: 展平
x_flat = x.view(-1, hidden_dim)

# Step 2: Router 打分
scores = F.softmax(
  self.gate(x_flat), dim=-1
)

# Step 3: Top-K 选择
topk_weight, topk_idx = torch.topk(
  scores, k=num_experts_per_tok,
  dim=-1, sorted=False
)

# Step 4: 归一化权重
topk_weight /= topk_weight.sum(
  dim=-1, keepdim=True
)

四个步骤拆解：

1️⃣ 展平：将 [batch, seq, hidden] 变成 [batch*seq, hidden]——每个 token 独立选择专家。

2️⃣ Router 打分：self.gate 是一个 Linear(hidden_size, num_experts)，输出每个 token 对每个专家的"偏好分数"，然后用 softmax 转成概率。

3️⃣ Top-K 选择：选得分最高的 K 个专家（MiniMind 默认 K=2）。

4️⃣ 权重归一化：对选中的 K 个专家的权重重新归一化，让它们加起来等于 1。

🔍 逐行代码解析

让我们仔细看网络的"选择"具体是如何实现的：

# self.gate 的定义
self.gate = nn.Linear(
  config.hidden_size, # 输入：token 的隐藏表示
  config.num_experts, # 输出：对每个专家的分数
  bias=False
)

# 假设：
# hidden_size = 768
# num_experts = 4
# gate 权重形状：[768, 4]

# 对 token "天气" 的推理
# gate("天气") → [2.1, 0.5, -0.3, 1.8]
# softmax → [0.50, 0.21, 0.09, 0.20]
# top-2 → 专家0(0.50) + 专家3(0.20)

这个网络选择，其实就是一个简单的线性层！

视频里说："门控网络原始输出的是原始的 logits，用来做 softmax 计算专家选择概率"。

简单说：

  • 输入：token 的 768 维向量
  • 输出：4 个分数（对应 4 个专家）
  • 选择：分数最高的 2 个专家

一个比喻：Router 就像一个分诊台护士——她听你说症状（token 的表示），然后判断该去哪个科室（专家）。

🔄 专家前向传播

选好专家后，怎么把 token 送到对应的专家那里？

# 对每个专家，找到分配给它的 token
y = torch.zeros_like(x_flat)
for i, expert in enumerate(self.experts):
  # 哪些 token 选了这个专家？
  mask = (topk_idx == i)
  if mask.any():
    token_idx = mask.any(dim=-1).nonzero().flatten()
    weight = topk_weight[mask].view(-1, 1)
    # 专家处理 token，加权累加
    y.index_add_(0, token_idx,
      (expert(x_flat[token_idx]) * weight)
    )

这里用了一个 for 循环遍历所有专家：

  1. 对每个专家 i，查哪些 token 选中了它
  2. 如果有，把这些 token 发给专家处理
  3. 乘以对应的权重
  4. 累加到输出 y 中

注意：一个 token 如果选了 2 个专家，它的输出就是两个专家输出的加权和。

🧪 具体例子：4 个专家，Top-2

假设一个 batch 只有 3 个 token，4 个专家，每个 token 选 Top-2：

TokenRouter 输出 (softmax 后)Top-2 专家权重
"天气"[0.50, 0.21, 0.09, 0.20]专家 0, 专家 3[0.71, 0.29]
"数学"[0.10, 0.70, 0.15, 0.05]专家 1, 专家 2[0.74, 0.26]
"代码"[0.05, 0.15, 0.75, 0.05]专家 2, 专家 1[0.79, 0.21]

可以看到：

  • 专家 0：处理了"天气"（权重 0.71）
  • 专家 1：处理了"数学"（0.74）和"代码"（0.21）
  • 专家 2：处理了"数学"（0.26）和"代码"（0.79）→ 代码的主要处理者！
  • 专家 3：处理了"天气"（0.29）

这就是专家分化的雏形——虽然训练初期可能很混乱，但训练充分后，专家 2 可能会变成"代码专家"。

📝 本章小结

  1. Router 就是一个简单的线性层：hidden_size → num_experts
  2. 网络选择 = Top-K：选概率最高的 K 个专家
  3. 专家输出加权求和：每个 token 的最终输出是选中的专家输出的加权和
  4. Router 的参数是可学习的：它通过反向传播学习如何分配 token
  5. 专家分化是训练的结果：初期混乱，后期逐渐分化
